CypressTestingAPI

My API testing portfolio projectMeu projeto de portfólio de testes de API

An end-to-end API test suite for the public ServeRest API, independent of any front end. Specs are organized by domain across three business flows: users and authentication (POST /usuarios, POST /login), products (POST and GET /produtos) and the cart from start to finish (POST and DELETE /carrinhos). Tests check status codes, messages, tokens and response data, and use @faker-js/faker for test data.Uma suíte end-to-end de testes de API para a API pública ServeRest, independente de qualquer front-end. As specs são organizadas por domínio em três fluxos de negócio: usuários e autenticação (POST /usuarios, POST /login), produtos (POST e GET /produtos) e o carrinho de ponta a ponta (POST e DELETE /carrinhos). Os testes validam códigos de status, mensagens, tokens e dados de resposta, e usam @faker-js/faker para gerar dados.
